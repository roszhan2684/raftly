# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback, and focus on what's best for the
community. Harassment and discrimination are not tolerated.

Report unacceptable behaviour privately to the maintainers via a GitHub Security Advisory or by contacting a maintainer
directly. Maintainers will review reports promptly and confidentially.
