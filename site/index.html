Why Raftly

Not a roadmap prompt. Not a code generator.

Code generators write code. Roadmap prompts write plans. Neither remembers why a decision was made, stops you overbuilding, or tells you the truth about launch readiness. Raftly is the organization around the code.

How it works

The judgment of a senior organization, behind one command

Raftly routes every decision to the right senior role: product strategy, design, architecture, security, SRE and 17 more. It decides what it can, researches what it can't, and asks you only the genuine business questions.

Orient

Reads your repo and its .raftly/ state. Works out the mode: greenfield, build, review, recovery, migration, launch.

Research

Checks what's current and uncertain against primary sources. Anything it couldn't verify is labelled not verified, never invented.

Decide

Routine choices are made silently. Important ones become recorded recommendations. Only business calls come to you, batched into one question.

Record

Every major decision becomes an ADR with options, confidence, consequences and a revisit trigger. Your overrides keep Raftly's original advice.

Design

2–3 genuinely different UI directions (different interaction models, not different colours), with a recommendation, full screen states and accessibility.

Plan

The simplest architecture that meets the actual requirements. Feature specs, a build graph and one prompt per capability.

Build & verify

/raftly build next implements the next unblocked node, runs your tests and records real evidence before anything is marked done.

Launch honestly

/raftly launch runs a production gate fitted to your product. No evidence means no PASS. "Not applicable" is a valid answer.

Proportionate by design

It refuses to overbuild

Same command, very different products. Raftly decides which production controls apply to your profile, so a calculator is never judged on missing Kubernetes.

What's inside

An operating system for building products with Claude

⌘

22 senior roles

From Head of Product Strategy to Principal SRE. Each decision is made by the discipline that should own it, and the reply says who decided.

✎

Decision records & overrides

ADRs with confidence, reversibility and revisit triggers. Overrule Raftly and it records your call, the consequences, and moves on without re-arguing.

Evidence graph

Requirement → feature → screen → API → table → test → metric. Ask "why does this exist?" or "which requirements have no tests?".

45 launch checks plus the commonly forgotten 20% (password reset, failed payments, restore drills…), each applied only when it fits your product.

Requirement change engine

Learning firewall

Install

Two commands. Then /raftly

Raftly installs into Claude Code once and works in every repository you open.

Inside Claude Code, add the marketplace and install the plugin:

# in Claude Code
/plugin marketplace add roszhan2684/raftly
/plugin install raftly@raftly

Then open any project and run:

/raftly I want to build ...

The same thing from your terminal:

claude plugin marketplace add roszhan2684/raftly
claude plugin install raftly@raftly

Update later with claude plugin update raftly@raftly.

No plugin system? Copy the self-contained skill folder into your personal skills directory:

git clone https://github.com/roszhan2684/raftly.git
mkdir -p ~/.claude/skills
cp -R raftly/skills/raftly ~/.claude/skills/raftly

The optional independent review agents only come with the plugin install.

Requires Claude Code and Python 3.9+ (standard library only). If another tool already owns /raftly, use /raftly:raftly.

FAQ

Questions

Does Raftly send my code or plans anywhere?

No. Raftly has no backend, no account and no telemetry. Everything it writes stays in your repository. Research uses whatever web tools your Claude session already has.

Will it ask me a hundred questions?

No. It decides routine things itself and records important recommendations. It only asks about genuine business decisions such as pricing or target customer, batched into a single round.

Can I use it on an existing, half-built repo?

Yes. Raftly inspects what exists, records it as current, initialises its state without touching your code, and builds a recovery plan. It never starts with a rewrite.

What if I disagree with a recommendation?

Tell it. It records your decision as a founder override, keeps its original recommendation and the consequences, and proceeds consistently with your choice.

Does it certify my product as secure or compliant?

No. Raftly provides engineering readiness analysis and evidence-based guidance. It flags items that need professional review and never claims certification.

Is it free?

Yes. Raftly is open source under the Apache License 2.0. You need Claude Code to run it.
