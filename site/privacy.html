Privacy policy

Effective 24 October 2026

The Raftly plugin

  • Raftly collects no personal data. It has no backend, no account, no analytics and no telemetry.
  • It runs inside Claude Code on your machine and writes files only to the project you run it in (the .raftly/ and artifacts/ folders).
  • Raftly never sends your code, plans or learnings to the Raftly author or to any Raftly server. None exists.
  • Claude Code itself, and any web research it performs, are provided by Anthropic and governed by Anthropic's terms and privacy policy, not by this policy.

This website

  • This site is hosted on GitHub Pages. It sets no cookies, uses no analytics and loads no third-party scripts or fonts.
  • If you switch the light/dark theme, the choice is stored only in your own browser (local storage). It is never sent anywhere.
  • GitHub, as the host, may process technical data such as IP addresses to serve the site. See the GitHub General Privacy Statement.

Contact

Questions: open an issue at github.com/roszhan2684/raftly/issues. For security reports, use GitHub's private vulnerability reporting on the repository.
