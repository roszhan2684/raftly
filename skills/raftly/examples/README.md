# Report shapes

Short examples of how `/raftly` replies. They show tone and structure, not content to copy. Every real
report is derived from the project's `.raftly/` state.

- [greenfield-report.md](greenfield-report.md): first invocation with an idea
- [resume-report.md](resume-report.md): `/raftly` with no arguments in an existing project
- [override.md](override.md): founder overrides a recommendation
- [challenge.md](challenge.md): an unnecessary technology request
- [preference.md](preference.md): a personal preference (Learning Firewall)
- [launch-report.md](launch-report.md): `/raftly launch` with incomplete evidence
