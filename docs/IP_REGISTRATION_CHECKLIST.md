# U.S. copyright registration checklist (optional)

> Planning checklist, **not legal advice**. Copyright exists without registration. Registration mainly strengthens enforcement
> options in the U.S. Nothing is filed automatically.

- [ ] **Owner identified**: the individual or entity that holds copyright (`legal/release-gate.yaml: legal_owner`). If an entity, confirm the code was created for it or assigned to it.
- [ ] **Version chosen**: register a stable release (e.g. `v0.1.0`). Record the commit hash and tag.
- [ ] **Deposit preserved**: keep an archive of the exact deposited source (e.g. `git archive v0.1.0`) and its checksum.
- [ ] **Third-party material excluded**: confirm against `THIRD_PARTY_NOTICES.md` (currently no bundled third-party code).
- [ ] **AI-assisted authorship reviewed with counsel**: much of this repository was generated with AI assistance under the owner's direction (`docs/PROVENANCE.md`). Current U.S. Copyright Office guidance requires disclosing AI-generated material that is more than de minimis, and limits claims to human-authored contributions (selection, arrangement, modification). Verify the current guidance and how to describe the human contributions.
- [ ] **Human contributions documented**: owner-authored specifications (`docs/specs/`), review and edit commits, design decisions.
- [ ] **Timing**: consider filing before or promptly after the public release.
- [ ] **Records kept**: application number, certificate, deposit copy, correspondence.

Related: trademark clearance and filing are separate (`docs/BRAND_CLEARANCE.md`). Patent questions only arise if counsel identifies
a genuinely novel technical invention, and should be discussed **before** public disclosure where timing matters.
