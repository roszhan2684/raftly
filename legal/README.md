# Legal and release status

- `release-gate.yaml`: machine-readable release blockers. `scripts/check_release.py` reports them as warnings during
  development and fails on them with `--release`.
- Decisions and options: `docs/LICENSING_STRATEGY.md` · brand: `docs/BRAND_CLEARANCE.md` · registration:
  `docs/IP_REGISTRATION_CHECKLIST.md` · authorship: `docs/PROVENANCE.md` · inventory: `THIRD_PARTY_NOTICES.md`.

Optional files to add once decisions are made: `CLA.md` (if a CLA is chosen), `COMMERCIAL_LICENSE.md` (dual licensing),
`TRADEMARK_POLICY.md` (once a cleared brand is in public use). Have each reviewed by counsel.

Nothing in this repository is legal advice.
